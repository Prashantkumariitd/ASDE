# ASDE Phase 3

## Objective
Build a persistent domain knowledge and scientific execution layer.

## Domain workstreams
- Quantum foundations
- CMB and observational cosmology
- Early universe and inflation
- Mathematical physics and information theory
- Quantum field theory and thermalisation
- Scientific computing
- Experimental evidence and data

## Scientific standards
- Traceable literature and DOI verification
- Explicit mathematical assumptions
- Independent derivations
- Reproducible computational experiments
- Quantified uncertainty
- Adversarial testing
- No unsupported claims of proof

## Execution constraints
- Cloud execution in the existing Colab master notebook
- Neon PostgreSQL for structured state
- Neon Object Storage for large artifacts
- GitHub for versioned source and research artifacts
- Groq primary; OpenRouter fallback only on HTTP 400
- No paid API or compute services
