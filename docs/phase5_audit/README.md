# ASDE Phase 5 — CHSH / Measurement Dependence

**Audit status: FROZEN — v1.0 (Qualified)**

Phase 5 investigates the minimum measurement dependence
required within a declared deterministic local hidden-variable
framework to reproduce the specified quantum CHSH correlations.

## Main result

\[
TV_{\min}=\frac{\sqrt{2}-1}{3}
\approx 0.1380711874576983
\]

Under the declared Hall metric convention \(M=2TV\):

\[
M_{\min}\approx0.2761423749153966
\]

The exact algebraic primal witness attains the analytical
lower bound for the declared finite model.

## Hall comparison

The reported Hall singlet model value
\(M_{\mathrm{singlet}}\approx0.276434\) is a separate,
model-specific result. It is not the LP minimum.

## Historical result

The old zero-TV result was invalidated after missing
constraints were identified.

The original historical LP implementation and exact constraint
ordering were not recoverable from the repository artifacts
examined. This does not prove they never existed.
